\section*{Data and Code Availability}

Transparency and reproducibility are core principles of this work.
Data and code availability are described below,
subject to ethical, legal, and institutional constraints.

\subsection*{Data availability}

The data used in this study consisted of clinical communication guidelines from the Ariadne Labs Essential Communications Toolkit, which is publicly available through the Ariadne Labs website. No patient data were collected or used in this study. Evaluation was conducted on synthetic clinical scenarios and through clinician feedback sessions during routine clinical meetings.

\subsection*{Code availability}

The consultation assistant source code is publicly available under the MIT License at:

\textit{``Code is available at \url{https://github.com/Arkoys/ai-essential-communication-for-dementia} for reproducibility.''}

The repository includes:
\begin{itemize}
    \item Frontend application code (React/TypeScript)
    \item LLM integration and RAG implementation
    \item Evaluation prompts and test scenarios
    \item Knowledge base construction scripts
\end{itemize}

Note: API keys for LLM providers are required for inference and are managed through environment configuration rather than included in the repository.
