\begin{abstract}

Dementia care in primary care settings presents significant diagnostic and communication challenges. Clinicians must navigate complex consultations involving cognitive decline, diagnostic uncertainty, emotional distress, and caregiver concerns. More than 55 million people worldwide live with dementia, with nearly 10 million new cases annually. Primary care clinicians are often the first point of contact, yet existing artificial intelligence (AI) systems focus mainly on documentation automation, providing limited support for communication-centered workflows. The aim of this project was to develop a guided consultation assistant using large language models (LLM) and evidence-based communication frameworks. This project was conducted in collaboration with the Ariadne Labs and the Harvard T.H. Chan School of Public Health.

This project developed a standalone web-based clinical support system combining retrieval-augmented generation with large language models, grounded in the Ariadne Labs Essential Communications Toolkit. The system integrated structured workflow navigation across three consultation phases: recognition, evaluation, and diagnosis. It also incorporated the Stuck Points Framework for addressing relational communication obstacles. Implementation used open-source web technologies with Firebase backend and support for multiple LLM providers.

The system successfully integrated the Navigation Map structure with LLM-powered conversational guidance, enabling source-faithful responses grounded in evidence-based resources. The Stuck Points Framework was implemented as a specialized module for relational support, while the dual-mode architecture allowed comparison between different LLM providers while maintaining evidence grounding.

This work demonstrates the feasibility of combining large language models with structured communication frameworks to support primary care clinicians in dementia consultations. The findings establish that retrieval-augmented generation can provide clinically relevant, source-grounded guidance for communication-centered workflows, supporting further development of communication-centered clinical AI tools.
